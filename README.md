# Sales Analytics Dashboard | Power BI

![Sales Dashboard](Screenshot 2026-06-12 015227(1).png)

## Project Overview

This project focuses on developing an interactive **Sales Analytics Dashboard using Microsoft Power BI** to transform raw sales data into actionable business insights.

The dashboard provides a comprehensive analysis of sales performance, profitability, product contribution, customer segments, and geographical trends. The goal of the project is to support data-driven decision-making by enabling stakeholders to monitor key performance indicators (KPIs), identify revenue drivers, and understand business performance patterns.

---

## Business Problem

Businesses generate large volumes of sales data but often lack efficient systems to convert this information into meaningful insights.

The project addresses key business questions:

- What is the overall sales and profitability performance?
- Which countries contribute the highest revenue?
- Which products generate the most sales?
- Which customer segments create the most value?
- How do sales trends change over time?

The dashboard provides a centralized reporting solution for performance monitoring and strategic planning.

---

## Objectives

- Build an interactive Power BI sales dashboard
- Analyse revenue, profit, and units sold
- Identify top-performing countries and products
- Analyse monthly sales trends
- Compare customer segment performance
- Create business-focused visual insights
